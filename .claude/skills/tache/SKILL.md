# /tache

Lire `WORKFLOW.md`, puis suivre intégralement `docs/workflow/tache.md`.
Ces fichiers sont la référence générique pour toute IA ; ce raccourci facultatif ne définit aucune règle distincte.

Dans un chantier, lire aussi `docs/workflow/chantier.md`, `docs/workflow/duo.md` et le dossier canonique du suivi.
L'IA qui a créé le chantier est Patrick. L'autre est Fanny. Seul Patrick communique avec l'utilisateur ; Fanny
écrit à Patrick dans `de-fanny.txt` et met sa fiche à jour à chaque arrêt. Les deux codent en parallèle, chacune
dans son worktree. Aucun sous-agent : le développeur réveille les deux sessions.
